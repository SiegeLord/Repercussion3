# Repercussion 3 

# Plot

You are trapped in a cave and need to escape to the surface.

## Default Controls

- *Arrows/Left Thumb* - Move
- *WASD/Right Thumb* - Drill
- *Space/A Button* - Jump
- *L Shift/B Button* - Grab/throw demon
- *E/X Button* - Eat demon
- *T/Left Shoulder* - Build torch
- *G/Right Shoulder* - Build support
- *J/Y Button* - Build jaunter
- *F5/Left Trigger* - Quicksave
- *F9/Right Trigger* - Quickload

# Gameplay Hints

- Watch out for demons exploding!
- Rocks need to support lest they collapse!

# Building instructions

1. Install Allegro 5.
2. Install Rust from rust-lang.org. You'll need the nightly version.
3. Run `cargo run --release` to build and run the game.

On Windows, you can use the pre-built binaries (extracted in the `allegro`
subdirectory). `run_msys.sh` may be useful for this purpose.

# Rules

1. *genre rule #157: It's a Zoo!* - You're encouraged to dig pens for glowy
   demons so they can breed better. You can collect them and sort them into
   such pens.
2. *art rule #84: Include references to the works of a science fiction author
   of your choice.*  - The enemies and some buildables are taken from works by
   Stephen King.
3. *tech rule #132: Catastrophic overflow: Chaos ensues as the capacity of some
   container is exceeded.*  - If you place too many demons into an enclosed
   space, they catastrophically explode.
4. *tech rule #116: If At First You Don't Succeed: The game must have a
   quicksave / quickload feature.*  - F5/F9 works
5. *bonus rule #31: Act of Sutskever* - Not used
